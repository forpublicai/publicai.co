## What is Cursor in Slack?

**Cursor** is an AI-powered coding assistant that can autonomously handle complex software development tasks. Through its background agent system, it can work on multi-step projects, from creating new features to fixing bugs to deploying changes.

When integrated with the Public AI Slack workspace, it becomes a collaborative team member that can:
- Generate complete features from simple descriptions
- Fix bugs and refactor code
- Write and run tests
- Create and merge pull requests
- Deploy changes to production

## How to Use Cursor in Slack

### Basic Workflow

Using Cursor in Slack is as simple as mentioning it with your request:

```text
@Cursor [your task description]
```

**Example:**
```text
@Cursor Create a new landing page for our product with a hero section,
features grid, and call-to-action buttons. Match our existing design system.
```

### Step-by-Step Instructions

1. **Mention `@Cursor` in a Slack channel:** Tag `@Cursor` in any message where you want AI assistance with a coding task.
2. **Provide a clear task description:** Include what you want to build or change, where it should go (file paths, repo names), and any styling or dependency constraints.
3. **Autonomous execution:** The agent explores the codebase, plans the implementation, writes the code, runs tests, and pushes a new branch.
4. **Review and merge:** The agent replies with a summary of changes and a PR link for human review.

## Best Practices

### Do's

- **Be Specific:** `@Cursor Add a dark mode toggle to the settings page using next-themes.`
- **Provide Context:** `@Cursor Fix the memory leak in the UserService when navigating between pages.`
- **Reference Files or Repositories:** `@Cursor In forpublicai/publicai.co, add a new post in content/projects/.`

### Don'ts

- **Avoid vague prompts:** `@Cursor Make the app better`
- **Avoid bundling unrelated tasks:** Break large unrelated tasks into separate PR requests.
